# 🦷 Dental Clinic Voice Agent

An AI-powered voice assistant built using **Vapi and OpenAI** to automate patient interactions, collect appointment details, and send appointment confirmation emails through workflow automation.

## 🚀 Project Overview

Dental clinics frequently handle repetitive phone calls related to appointments and general enquiries. Managing these interactions manually can increase the workload for reception staff.

This project demonstrates how an AI voice agent can communicate naturally with patients, collect the information required for appointment requests, and trigger automated email confirmations through connected tools.

The goal is to make patient interactions more convenient while reducing repetitive administrative work.
